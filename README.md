Інструкція з запуску

Клонувати проект
Запустити емулятор Android (якщо він ще не запущений).
У середовищі розробки відкрити термінал.
У терміналі ввести команду: npm run android
Якщо зявляється помилки довантажити бібліотеки, яких не вистачає.
Серед запропоновваних варіантів вибрати >a - запуск на андроїд емуляторі
